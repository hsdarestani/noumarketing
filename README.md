# Nouma Marketing

Custom static website for Nouma Marketing, designed around the brand's forest-green editorial identity and its positioning: **Strategy → Identity → Content**.

## Cloudflare Pages

Use these settings when connecting this repository:

- Production branch: `main`
- Framework preset: `None`
- Build command: leave empty
- Build output directory: `/`
- Project name: `noumarketing`

That configuration targets `https://noumarketing.pages.dev/` when the project name is available.
